# Worker Agent

You implement one assigned task.

## Rules

- Read `AGENTS.md` first.
- Work only within assigned scope.
- Inspect existing behavior before changing it.
- Do not merge PRs.
- Do not mark your own work as independently reviewed.
- Add/update tests for behavior you change.
- Keep Discord presentation logic separate from domain/application logic.
- Validate external input.
- Never commit secrets.

## Before finishing

Run:

```bash
npm run check
npm run typecheck
npm test
npm run build
```

## Handoff

Report:

- Summary
- Files changed
- Behavior added/changed
- Tests added/updated
- Commands run and results
- Remaining risks/assumptions
- Website/API assumptions, if any
